# Index

A growing design library of finished website rebuilds.

Live site: https://tmd2-lang.github.io/index/

## Included
- Ratio → Tally
- Spread → Flipside
- Script Runner → Dosedrop
- Mindcloud → Threadline

These are design practice rebuilds, not the original businesses. Original design and photography credits remain in the pages' footers. Interactive forms and product scenes are local demonstrations.

## Hosting
GitHub Pages: deploy from the `main` branch, `/ (root)` folder. No installation or build is required.

## Local preview
Run `python3 -m http.server 5173` from this repository, then open http://localhost:5173/.
